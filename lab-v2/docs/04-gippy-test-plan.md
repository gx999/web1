# 지피(ChatGPT) 연결 시험 절차 — 3단계

상태: **시험 전**. 아래 결과를 받기 전에는 어떤 경로도 '연결 완료'로 표시하지 않는다.
시험 대상은 격리된 Notion 페이지 「연구소 v2 · 실행기반 시험 (격리)」의 「작업 대기열 (시험)」뿐이다.
기존 ChatGPT 연구소(Sites 서버·예약)와 「업무 통합 관리」에는 **아무것도 쓰지 않는다**(읽기 목록 확인만).

## 1단계 — 지피가 쓸 수 있는 연결 확인 (읽기만)
1. ChatGPT 설정 → 앱(플러그인/커넥터) 화면에서 **Notion**과 **기존 연구소 MCP**(ChatGPT Sites 연구소 서버)가 연결돼 있는지 화면을 확인한다.
2. 지피에게 입력:
   > 지금 이 대화에서 쓸 수 있는 앱·커넥터와 각각의 도구 이름을 있는 그대로 나열해 줘. 실행은 하지 마.
3. 기록할 것: 연결 이름, 도구 이름 목록, 계정(어느 Notion 워크스페이스), 개발자 모드 필요 여부.

통과 기준: Notion 도구에 읽기(검색·조회)와 쓰기(페이지 생성·수정)가 모두 보이면 2단계로.

## 2단계 — 사람이 있는 상태에서 읽기·쓰기
지피에게 입력:
> Notion에서 「작업 대기열 (시험)」 데이터베이스를 찾아 모든 행의 과제ID와 상태를 그대로 보여줘.
> 그다음 같은 데이터베이스에 새 행을 하나 추가해 줘: 과제ID `G-1-지피등록-시험`, 단계 `시험`, 상태 `queued`, 담당역할 `지피 등록 시험`, 시험 체크.

기록할 것: (a) 읽은 행 목록이 실제와 같은지(현재 T-A·T-B=blocked, T-C·T-D=done), (b) 쓰기 전에 **승인 카드**가 떴는지와 몇 번 눌렀는지, (c) 오류 문구.
**Claude 쪽 대조:** 결과를 알려 주시면 내가 Notion에서 `G-1` 행의 존재·생성 시각을 직접 조회해 지피의 보고와 대조한다.

(선택) 기존 연구소 MCP: 지피에게 "기존 연구소 연결의 상태 조회 도구만 호출해 결과를 보여줘. 과제 생성·변경은 하지 마."
→ 기존 경로가 살아 있는지만 확인. 기존 기록은 변경하지 않음.

## 3단계 — 사람이 없는 상태(ChatGPT 예약 작업)
1. ChatGPT에서 **1회성 예약 작업**을 10~15분 뒤로 만든다:
   > Notion 「작업 대기열 (시험)」의 행 수와 상태별 개수를 조회하고, 새 행 `G-2-지피예약-시험`(단계 시험, 상태 queued, 시험 체크)을 추가해. 실패하면 오류 문구를 그대로 남겨.
2. 예약 시각에는 ChatGPT 화면을 열어 두지 않는다(승인 카드를 누르지 않음).
3. 기록할 것: 예약 실행 여부·시각, 조회 성공 여부, `G-2` 생성 여부, 승인 대기로 멈췄는지.
**Claude 쪽 대조:** `G-2` 행의 실제 존재를 내가 조회해 확인한다.

## 결과에 따른 저장 위치 판단 (결정은 사용자)
| 시험 결과 | 함의 |
|---|---|
| 2단계 통과, 3단계 쓰기도 통과 | Notion을 지피–연구소 공유 원장으로 쓸 수 있음. Claude 측 쓰기 승인 문제는 별도 해결 필요 |
| 2단계 통과, 3단계 쓰기 실패(승인 대기) | 지피는 사람이 있을 때만 과제 등록 가능. 예약 보고는 읽기 전용 |
| 2단계부터 쓰기 불가 | Notion은 조회용. 과제 등록은 기존 연구소 MCP 또는 새 원장 서버 필요 |
| 기존 연구소 MCP 조회 성공 | 기존 경로 확장안(승인 필요)이 현실적 후보로 남음 |

인증정보는 어느 단계에서도 채팅에 붙여 넣지 않는다.
